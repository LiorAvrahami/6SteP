# reference/

The footwork of the elements was read from David Drysdale's Lindy Hop notes ("lurklurk"), written in a compact move
notation: <https://lurklurk.org/lindyhop/index.html>, notation key <https://lurklurk.org/lindyhop/notation.html>.

Those pages say "Copyright © David Drysdale 2006-2008; all rights reserved", so they are **not** in this public
repository. On the user's PC a copy sits next to this file in `reference/lurklurk/` (git-ignored: `lindyhop.zip` as
downloaded, the pages in `site-with-codes/`) and in `C:\Liors_Stuff\Swing5\reference\`. Anywhere else, read the site
online.

The codes in `dance/skeletons.json` (`eFL2R`, `Df`, `X`, `T`, `R`, ...) are the notation used as data, not copied text.
`old handovers/handover-reading-the-notes.md` explains the notation, and `footwork-sources.md` lists the page each element
came from.
